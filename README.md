# Gym Warden PWA v0.6

A lightweight iPhone-installable PWA for tracking a flexible weekly weight-training target. v0.6 updates the in-app mascot and Home Screen icons to the black cat with yellow eyes.

## v0.6 behavior

- Weekly target defaults to 4 weight-training days.
- Week starts on Sunday by default.
- Debt defaults to $100 per missed workout.
- One action: Log completed workout.
- No start proof, finish gate, timer, fixed workout names, reminders, nudges, SMS, or backend.
- Photos/screenshots are previewed only and are not saved.
- Local storage keeps small metadata only: date, proof type, notes, target, and week history.
- Export/import backup is available for workout history and settings.

## Deploy to GitHub Pages

Upload these files to the repository root:

- index.html
- styles.css
- app.js
- manifest.webmanifest
- service-worker.js
- README.md
- icons/icon-192.png
- icons/icon-512.png
- icons/cat-mascot.png

Then enable GitHub Pages from the repository root.

## Install on iPhone

Open the GitHub Pages URL in Safari, tap Share, then Add to Home Screen.
